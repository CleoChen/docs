独立 IP 是 Sendify 提供的付费增值服务，适合希望长期经营发信信誉、且有持续发信需求的团队。通过专用的发信 IP，您可以减少共享 IP 上其他发件人行为带来的影响，让自己的发送表现逐步积累为 IP 信誉。

## 独立 IP 可以做什么？

### 建立自己的发信信誉

Sendify 默认使用共享 IP 通道发送邮件。使用独立 IP 后，您可以通过持续、稳定的高质量发送，建立并维护自己的 IP 信誉。

独立 IP 有助于提升发信信誉的可控性，但邮件能否进入收件箱，还取决于域名信誉、身份认证、联系人质量、邮件内容和收件人的反馈。购买独立 IP 不代表邮件一定进入收件箱。

### 通过 IP 池管理发送通道

您可以将购买的独立 IP 加入 IP 池，再将需要使用该通道的发信地址关联到 IP 池。关联后，这些地址发送的邮件将优先使用独立 IP 投递。

### 逐步建立新 IP 的发送能力

新 IP 需要通过预热，逐步提高发送量，让收信服务商了解您的发送行为。请在控制台确认预热设置，并在正式大规模发送前预留预热时间。

启用自动预热时，系统会根据预热阈值分配流量，超出阈值的部分可转由共享 IP 通道投递。因此，预热期间部分邮件使用共享 IP 属于正常情况。

## 什么样的客户适合购买？

建议结合发送频率、联系人质量和运营能力判断，而非只看单次发送量。

| 您的情况 | 建议 |
| --- | --- |
| 持续开展邮件营销，发送量相对稳定，希望长期积累品牌的发信信誉 | 适合评估独立 IP |
| 已有清晰的订阅来源，能持续维护联系人、处理退信和投诉 | 具备经营独立 IP 信誉的良好基础 |
| 对发送通道有明确管理需求，并愿意投入时间预热和监控 | 适合结合业务规模评估 IP 数量与配置 |
| 刚开始使用邮件营销，发送量较少或频率不固定 | 建议先使用共享 IP，待发送模式稳定后再评估 |
| 仅为一次活动临时大量发送，无法安排预热 | 建议先规划发送节奏，再决定是否购买 |
| 希望通过更换 IP 解决高退信、高投诉或垃圾箱问题 | 应先排查联系人、认证和内容，独立 IP 无法替代这些基础工作 |

以上为选购建议，并非 Sendify 的购买门槛。稳定、可预测的发送有助于维护独立 IP 信誉。

## 如何购买并开始使用？

1. **进入独立 IP 页面。** 登录 Sendify，依次打开「账号头像 → 设置中心 → 发信设置 → 独立 IP」。

   <Frame>
     ![在设置中心的发信设置菜单中进入独立 IP 页面](/dedicated-ip-entry.png)
   </Frame>

2. **购买独立 IP。** 点击「购买独立 IP」，按购买页提示确认规格、数量、购买时长和费用，完成支付。具体可选项及价格以购买页展示为准。
3. **创建 IP 池。** 返回独立 IP 管理页面，新建 IP 池，并将购买的 IP 加入池中。IP 池用于集中管理供发信地址使用的 IP。
4. **关联发信地址。** 将需要使用独立 IP 的发信地址关联到对应 IP 池。购买完成后，还需完成关联，邮件才会优先通过该通道投递。
5. **确认预热设置并开始发送。** 从活跃、明确订阅的联系人开始，逐步增加发送量，并持续观察退信、投诉及投递表现。

## 购买前常见问题

### 需要购买几个 IP？

可以从「一个 IP 是否能满足发送需求」「是否需要隔离不同业务」「是否需要独立 IP 备用通道」三个方面判断。

**以下情况可以考虑先购买 1 个 IP：**

- 主要用于同一类业务，例如同一品牌的订阅营销邮件，没有单独隔离不同业务信誉的需求。
- 发信频率和发送量相对稳定，预热后的实际投递表现能满足您要求的发送时间窗口，无需额外 IP 分担流量。
- 能接受单个 IP 异常时发送受到影响，或在已启用且可用的情况下接受共享通道退避，不要求始终通过独立 IP 发送。

例如，团队定期向已订阅客户发送同一品牌的资讯邮件，发送时间安排较灵活，可以先评估 1 个 IP。若发信量很少或间隔很长，建议先使用共享 IP。

**以下情况建议评估 2 个或更多 IP：**

| 需求 | 为什么需要多个 IP | 配置时需要注意 |
| --- | --- | --- |
| 提高业务连续性 | 单个 IP 或其所在机器异常时，需要其他可用的独立 IP 承接发送 | 备用 IP 也需要预热并持续维护信誉；购买后需完成相应配置 |
| 隔离不同业务的 IP 信誉 | 希望将营销邮件与重要通知，或不同品牌的邮件分别管理，减少业务之间的 IP 信誉影响 | 应使用不同 IP 池并关联对应发信地址；仅购买多个 IP 后全部放在同一个池中，不能实现业务隔离 |
| 分担较大的持续发送量或峰值 | 单个已预热 IP 在目标收信服务商的接收限制下，无法在要求的时间内完成发送 | 应结合投递数据评估扩容，新增 IP 仍需预热，不能购买后立即承担全部峰值 |

出于业务连续性与容灾考虑，[Sendify 官方说明](https://help.aliyun.com/zh/sendify/dedicated-ip)通常建议购买至少 2 个发信 IP。对于没有独立 IP 备用要求、业务单一且发送节奏稳定的团队，可结合预算和实际投递表现评估是否先使用 1 个。

**不要仅按「每天多少封」直接换算 IP 数量。** 同样的日发送量，分散在全天发送与集中在短时间内发送，对 IP 的要求不同；收件人集中在同一家邮箱服务商时，也会受到该服务商接收策略的影响。多个 IP 不保证发送速度按数量成倍提高，也不能用于绕过收信服务商的限制。

购买前，建议准备近期日均发送量、峰值时段发送量、期望完成时间，以及 Gmail、Outlook 等主要收件邮箱的占比，由服务团队协助评估。每个 IP 都需要足够稳定的发送来维护信誉，数量过多可能导致流量过于分散。

### 购买后可以立即全量发送吗？

新 IP 应逐步预热。请勿在刚开通时突然发送全部邮件，尤其是在同时使用新域名或新联系人列表的情况下。预热节奏需根据实际投递表现调整。

### 使用独立 IP 后，还需要验证发信域名吗？

需要。独立 IP 和域名身份认证承担不同作用。发送前仍应完成[发信域名设置](/sending-domain)，并持续维护联系人质量、提供便捷的[退订方式](/unsubscribe)。

### 独立 IP 支持退订吗？

Sendify 官方说明：独立 IP 使用后会影响 IP 信誉，不支持退订。请在购买前确认数量和使用计划，并核对订单页条款。

### 不确定是否适合购买？

请向 Sendify 服务团队提供近期日均发送量、峰值发送量、发送频率、主要收件邮箱类型，以及当前遇到的投递问题，便于评估是否需要独立 IP，以及合适的数量和预热安排。

如果对购买独立 IP 有任何疑问，请发送邮件至 [sendify-support@dingmail.work](mailto:sendify-support@dingmail.work)，联系 Sendify 客服团队。
