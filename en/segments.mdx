## What is a segment?

A segment is a dynamic recipient group built by filtering contacts with one or more rules. For example, you could create a segment for customers with a March birthday.

<Frame>![Configure segment rules](/segment-rules.png)</Frame>

## Automatic updates

Enable **Automatically update data** to add matching contacts to the segment each day at midnight.

## Use segments in a campaign

Select one or more segments when creating a campaign. Contacts that belong to multiple selected segments are counted only once.

<Frame>![Select segments in a campaign](/select-segments.png)</Frame>

## Segments vs. tags

|  | Tags | Segments |
| --- | --- | --- |
| Membership | Applied manually | Matched automatically by rules |
| Updates | Maintained manually | Can update automatically |
| Best for | Stable attributes or ad hoc groups | Dynamic groups based on attributes or behavior |
