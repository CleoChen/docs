## What is a tag?

A tag is a label for organizing and finding contacts. Use tags for known attributes, similar to labels in a CRM.

<Frame>![Contact tag example](/tags-example.png)</Frame>

## Use tags in a campaign

When creating a campaign, select recipients by tag. If a contact belongs to multiple selected tags, Sendify counts and sends to that contact only once.

<Frame>![Select tags in a campaign](/select-tags.png)</Frame>

<Tip>Use a consistent naming convention such as `Region-North America` or `Industry-SaaS`.</Tip>
