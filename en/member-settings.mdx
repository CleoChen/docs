## User types

- **Standard user:** Can manage contacts, send campaigns, review analytics, edit templates, and manage sender or reply-to addresses assigned to their account.
- **Administrator:** Has all standard capabilities plus domain, user, sender-address, and reply-to-address administration.

## Create a user

<Note>Only administrators can access this feature.</Note>

Open `System Management → User Management`, select **New user account**, and enter the login name, display name, and password.

<Frame>![User-management list](/member-user-list.png)</Frame>
<Frame>![Create a user account](/member-create.png)</Frame>

## Edit a user

<Note>Only administrators can access this feature.</Note>

Select **Edit** in the user list to update the user's display name or password. The login name cannot be changed after creation.

<Frame>![Edit a user account](/member-edit.png)</Frame>

## Assign sender addresses

<Note>Only administrators can access this feature.</Note>

Open `System Management → Sender Addresses`, select **Assign account**, and choose one or more users. Administrators can use all sender addresses by default.

<Frame>![Sender-address list](/member-sender-list.png)</Frame>
<Frame>![Assign a sender address](/member-associate.png)</Frame>

## View sender addresses

- Administrators can view every address in the organization and its assigned users.
- Standard users can only view addresses assigned to them.

<Frame>![Assigned sender addresses](/member-sender-view.png)</Frame>
