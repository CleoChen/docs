---

整个接入过程只需要创建一个 API Key、配置客户端并执行一次真实查询。

<Steps>
  <Step title="创建 API Key">
    打开 Sendify 控制台，进入以下位置：

    ```text
    开放能力 / API 密钥 / 创建密钥
    ```

    建议用“人员 + 客户端”的方式命名，例如 `lili-codex-desktop`、`marketing-team-cursor` 或 `reporting-claude-code`。

    <Warning>
    API Key 的完整内容只展示一次。请立即保存到密码管理器或客户端的密钥存储中，不要放入 Git、公开文档或共享的 AI 对话。
    </Warning>

    ![Sendify 控制台中的 API 密钥入口](/images/mcp-create-api-key.png)
  </Step>

  <Step title="选择并配置客户端">
    使用以下固定信息连接 Sendify MCP：

    ```text
    URL: https://mcp.sendify.dingstore.cn/dmx/mcp/v2
    Authorization: Bearer YOUR_API_KEY
    ```

    不同客户端的具体配置方式请参阅 [配置 AI 客户端](/mcp/client-config)。
  </Step>

  <Step title="执行真实查询">
    完全重启客户端，然后提出：

    > 列出我最近的 20 个 Sendify 营销活动，返回名称、状态和活动 ID。

    如果结果中出现你账号下真实的活动名称和活动 ID，说明连接、认证与数据权限均已生效。
  </Step>
</Steps>
