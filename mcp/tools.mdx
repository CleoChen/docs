Sendify MCP 当前提供营销活动、活动报告、收件人和联系人相关的只读查询工具。

## 工具列表

| 工具 | 用途 |
| --- | --- |
| `list_campaigns` | 分页列出营销活动，并获取真实活动 ID |
| `get_campaign` | 根据 `id` 查询活动摘要 |
| `get_campaign_report` | 根据 `campaignId` 查询活动统计数据 |
| `list_campaign_recipients` | 分页查询活动收件人及互动状态 |
| `get_campaign_recipient_by_email` | 查询某个邮箱在指定活动中的状态 |
| `list_contacts_by_offset` | 分页查询账号下的联系人 |
| `get_contact_by_email` | 按邮箱精确查询联系人 |

<Tip>
如果你只知道活动名称，应先让 AI 调用 `list_campaigns` 找到真实活动 ID，再查询详情、统计或收件人。不要让 AI 猜测 ID。
</Tip>

## 推荐提问

### 查找营销活动

> 列出我最近的 20 个 Sendify 营销活动，返回名称、状态和活动 ID。

### 分析活动效果

> 先找到名称包含「秋季上新」的营销活动，再查询它的发送成功数、独立打开数和独立点击数。

### 查看点击收件人

> 查询活动 ID 为 CAMPAIGN_ID 的已点击收件人，每页 50 条，并说明总数和当前页范围。

### 查询联系人

> 查询联系人 person@example.com 的资料。只返回 Sendify 实际提供的字段，不要补全缺失信息。

## 结果校验建议

- 要求 AI 返回活动或联系人的真实标识，便于在控制台交叉核对。
- 涉及分页时，要求说明总数、当前页范围和是否还有下一页。
- 不要把 AI 推测的字段当作 Sendify 返回值；可以明确要求“只返回实际提供的字段”。

<Warning>
当前 MCP 不支持写操作。任何“已创建联系人”“已创建活动”或“已发送邮件”的回答都不应被视为真实执行结果。
</Warning>
